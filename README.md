# Serverless Loan Orchestrator

## Overview

Flujo serverless para la generación de préstamos a clientes de un banco. Cubre desde la validación del usuario,
verificación de capacidad de pago, hasta el desembolso del préstamo hacia la cuenta destino.

**Stack:** Typescript · AWS (LocalStack) · SQS · DynamoDB · Lambda · Step Functions
